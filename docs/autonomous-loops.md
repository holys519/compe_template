# 自律ループ（CEM/ES → screen → 確認 → 焼き込み → push）の設計基準

1. **作る前に 1 ラウンド手で回して SE を測る**。既存最良（同じ候補）を各世代で再評価し、世代内の sd と「24 候補の最大値の期待値（best − median ≈ +1.5〜2 sd）」を把握する。
2. 置換閾値は SE の 2 倍以上。評価は世代ごとに**新規 seed**、ラウンド間で分布（mu/sigma）を引き継ぐ（毎回既定値に戻すと学習しない）。pop ≫ 次元（85 次元に 24 個体は誤設定）。
3. 確認は fresh seed で 1 回、α=0.005（800 seed）。採用時のみ焼き込み・push。README と台帳は自動追記（別ファイル）。
4. 完全性チェック: n == 予定 seed、両席、エラー 0、telemetry のフォールバック 0。`paired()` が欠損を黙って捨てない。
5. 停止ファイル・状態ファイル・停止後の再開。実行中に zplanner 等を編集すると途中から挙動が変わる（knob 既定オフで追加）。
6. **ノブ探索の天井を早く見極める**: 全候補の分布幅（例: 48.9k〜72.0k）が目標との差（56k）より一桁小さければ構造の問題。30 万試合回しても埋まらない。
7. 自律ループは成果の数字だけでなく「宣言どおりに回っているか」を 1 日 2 回人が確認する。
