# 他人の公開 agent（録画・テープ）の上に層を積むときの前提リスト

- **雇用時刻**: 追加 HIRE を親より早い時刻に入れると、親の雇い手の出現タイル（最も空いている倉庫タイル）が変わり、記録済み経路が全部ずれる（−5k/試合）。追加雇用は親の最終雇用より後の時刻に。
- **共有在庫**: 種・飼料・肥料・家畜は親と同じ在庫。種は同一手の PLANT 合計が在庫を超えると**全部**取り消し。追加層の PLANT は出力時に再上限。親の飼料小麦を売らない。
- **ユニット整列**: 親の `hand_align`（手の数に合わせて pad/truncate）と層のユニット番号の整合。
- **市場の順序**: 注文は index ごとに両者 lockstep で約定。追加注文は末尾に、10 件上限。
- **同一 seed ≠ 同一世界**: 層が空きタイル数を変えると乱数消費が変わり店が変わる。
- **無言失敗**: 親が例外を PASS に丸める実装なら、層のバグは「エラー 0」で隠れる。telemetry を層にも付ける。
- **測り方**: 親のクローンとの対戦は $0 tie が大半（kaggriculture 366/400）。tie を勝ちに変える +$1 の非干渉層と、生産を変える層を分けて評価する。
